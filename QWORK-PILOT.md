# План пилота qwork

Пилот охватывает один договор: от графика командировок до отчётов по объектам и сверки поступившей оплаты. Команда проверяет весь процесс на примере договора, по которому уже были выезд, закрытая задача и платёж.

## График и командировки

График Тайыра ведётся в годовой таблице: даты идут по строкам, сотрудники по столбцам, объекты указаны в ячейках. В qwork уже есть импорт Excel с черновиками по логину сотрудника. Для пилота нужно добавить чтение годового графика.

1. На предпросмотре импорта qwork показывает сотрудников, объекты и даты. Тайыр проверяет границы поездок и указывает связанный договор. Отпуск, выходной и работу из офиса не переносим в задачи по объектам.
2. Сотрудник проверяет готовый черновик и отправляет его по действующему маршруту согласования. После согласования появляются задачи по объектам.
3. По правилу Тайыра, несколько дней на одном объекте в одной поездке объединяются в одну задачу для сотрудника, в том числе через обычные выходные. Если на объект едут двое, у каждого своя задача. После перерыва в две недели создаётся новая задача. Неоднозначные разрывы в графике Тайыр проверяет на предпросмотре. Повторный импорт того же графика не создаёт дублей.

## Отчёт по объекту

Карточка Bitrix №43528 показывает три пункта: «Посещено», «Подтверждающие документы» и «Подтверждение с Е-кызмет». В карточке также требуется результат работы.

В qwork сотрудник получает задачу с объектом и плановыми датами. Он отмечает фактические посещения, описывает результат и прикладывает документы. Подтверждение из Е-қызмет обязательно для сдачи отчёта. Руководитель проверяет отчёт и при необходимости возвращает его на доработку.

## Договор, документы и оплаты

После вступления договора в силу команда планирует выезды, а бухгалтерия готовит график оплат. В карточке договора qwork показывает план и фактические поступления отдельно. В примере по ТМ-Маркет 773 000 ₸ в ноябре — плановая сумма. Факт добавляем по подтверждённым данным бухгалтерии, сохраняя сумму и дату каждого поступления. Это позволяет показать остаток при частичной оплате.

После закрытия работ в схеме процесса ГЗ готовит АВР, а бухгалтерия оформляет ЭСФ. На пилоте реквизиты документов и данные об оплате можно внести по предоставленному примеру. Тайыр запрашивает данные об оплатах у бухгалтерии. Жанар уточнила, что предоставляет анализ договоров. Какие суммы содержит этот анализ и кто отвечает за запись поступлений в 1С, нужно проверить на примере.

## Что сверить по следующим примерам

- **У Тайыра** — закрытая задача с заполненным результатом и подтверждением из Е-қызмет, чтобы определить формат приложения. Также нужен пример данных об оплате, которые ему передаёт бухгалтерия.
- **По анализу договоров** — одна строка, чтобы понять, где указаны план, фактическая оплата и остаток.
- **У ответственных за АВР, ЭСФ и поступления** — что нужно для выпуска документов, к чему их привязывают (договору, этапу или периоду) и по какому полю в выгрузке 1С можно сопоставить платёж с договором.

Для проверки достаточно примеров по одному договору. На пилоте используем копию графика и предоставленные образцы документов и платежей. Решение об автоматическом получении данных принимаем после сверки этих примеров.
