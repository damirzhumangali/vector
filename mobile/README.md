# qwork

Мобильный прототип управления выездными работами для iOS и Android. React Native и Expo SDK 58. Для запуска нужен Node.js 22.13 или новее.

## Запуск с общими данными

1. Запустите [бэкенд](../backend/README.md) на компьютере.
2. Скопируйте `.env.example` в `.env.local` и задайте `EXPO_PUBLIC_QWORK_API_URL` с адресом компьютера в Wi-Fi сети и портом API.
3. Из папки `mobile` выполните команды ниже. Если пользуетесь `nvm`, сначала выполните `nvm use`.

```sh
npm ci
npm start -- --lan
```

Откройте QR-код на двух телефонах в совместимой версии Expo Go. Для локального API телефоны должны иметь доступ к компьютеру по сети.

## Срочные уведомления

Для push нужна нативная сборка qwork с привязанным проектом Expo и настроенными APNs для iOS или FCM для Android. Приложение берёт идентификатор проекта из конфигурации Expo. Для сборки без записанного идентификатора можно задать `EXPO_PUBLIC_QWORK_EAS_PROJECT_ID`.

После входа откройте «Профиль → Срочные уведомления» и разрешите доставку на устройстве. Нажатие на уведомление открывает раздел рабочего времени.

## Проверка на двух телефонах

На первом телефоне зарегистрируйте компанию. Создатель получает роль диспетчера и в дальнейшем входит по рабочей почте и паролю без ссылки компании. Создайте сотрудника с уникальным в qwork логином вроде `ivan.petrov`. Почту можно указать по желанию. Временный пароль система создаёт автоматически. Затем назначьте сотруднику заявку.

На экране выдачи доступа нажмите «Отправить ссылку, логин и пароль». Сообщение включает все данные для первой активации. На втором телефоне откройте ссылку или нажмите «У меня есть приглашение». После проверки логина и временного пароля сотрудник устанавливает личный пароль. Ссылка действует 7 дней и погашается после завершения активации. Для следующих входов, включая другое устройство, достаточно логина и личного пароля. Заявки и изменения статусов синхронизируются с диспетчером. Руководитель активируется так же, с назначенной ему ролью.

Если сотрудник забыл пароль, создавший компанию диспетчер открывает «Команда» → «Сбросить пароль», получает новый временный пароль и выдаёт новое приглашение. Старые сеансы завершаются, а при активации сотрудник выбирает личный пароль. Подтверждение дополнительной почты доступно в профиле. После подтверждения можно входить по логину или почте и восстанавливать пароль через «Забыли пароль?». Для писем нужно настроить почтовый сервис на сервере. До подключения сервиса пользуйтесь логином и сбросом через диспетчера. Для старых аккаунтов с одинаковыми логинами в разных компаниях предусмотрен вход по ссылке компании.

«Открыть демо» запускает сценарий с переключением ролей. В серверном режиме роли назначаются учётным записям.

При создании заявки диспетчер выбирает сохранённый объект или ставит точку на карте. После создания он может приложить материалы из галереи. Сотрудник нажимает «Я на месте» и разрешает доступ к геопозиции. Сервер проверяет радиус объекта. Если GPS недоступен, сотрудник указывает причину ручной отметки.

Снимки «до» и «после» сотрудник делает камерой qwork. Сервер проверяет размер, яркость и резкость, сохраняет загруженный JPEG или PNG в исходном виде и показывает копию с водяным знаком. Лимит загрузки — 12 МБ и 16 Мп на снимок. Для отправки нужны оба снимка, заполненный чек-лист и описание результата. Диспетчер открывает заявку со статусом «На проверке» и нажимает «Принять работу» или возвращает её на доработку с причиной. Диспетчер и руководитель могут отклонить снимок с причиной. Доработка остаётся в той же заявке, повторный выезд создаётся отдельно и виден в истории.

Диспетчер отвечает за весь путь заявки: создание, назначение, проверку отчёта, приёмку и повторные выезды. Руководитель контролирует сроки и показатели, разбирает спорные случаи и сохраняет возможность проверить и принять отчёт. Для обычного завершения заявки отдельный вход руководителя не нужен. История показывает имя того, кто принял работу или вернул её на доработку.

Сотрудник, диспетчер и руководитель могут настроить PIN для быстрого входа на своём устройстве после обычного входа или через «Профиль → Быстрый вход». Для каждого аккаунта PIN задаётся на этом телефоне отдельно; при смене аккаунта прежний быстрый вход очищается. На iPhone Face ID и Touch ID требуют отдельной нативной сборки qwork. Ссылки Expo Go действуют в сети, из которой доступны Metro и API.

Для работы через мобильный интернет укажите публичный HTTPS-адрес API в `EXPO_PUBLIC_QWORK_API_URL` и HTTPS-адрес сервера приглашений в `EXPO_PUBLIC_QWORK_INVITE_URL` без пути. Новые персональные ссылки будут вести на `/join#…` этого сервера. Сотрудник может вставить такую ссылку на экране входа. Для самостоятельного запуска без Metro нужна установленная сборка приложения с этими настройками.
